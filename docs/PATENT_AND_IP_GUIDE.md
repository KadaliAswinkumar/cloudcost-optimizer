# Patent and IP Registration Guide (Founder Playbook)

Last updated: May 2026  
Important: this is operational guidance, not legal advice. Work with a qualified IP attorney before filing.

## 1. What to Protect

Prioritize novel and defensible elements:

- Recommendation confidence scoring tied to metric completeness and coverage quality.
- Lifecycle verification framework (accepted -> in_progress -> implemented -> verified -> rollback).
- Savings regression anomaly logic linked to realized-vs-estimated deltas.
- Investor-grade conversion telemetry model for FinOps execution.
- Multi-layer cloud intelligence architecture (FinOps + infrastructure + action proof loops).

## 2. Filing Strategy

Recommended sequence:

1. Document invention disclosures (problem, method, claims, alternatives).
2. File a provisional application quickly.
3. Validate market traction and technical evolution.
4. Convert to full specification before provisional deadline.
5. Evaluate PCT filing if international protection is planned.

## 3. Documentation Checklist

- Architecture diagrams.
- Data model and flow diagrams.
- Rule definitions and scoring formulas.
- Sample outputs and investor reporting artifacts.
- Prior art references and differentiation notes.

## 4. Jurisdiction Starter Path (India-first)

- Conduct patentability and prior art search.
- File in India first for priority.
- Decide whether to expand internationally via PCT.

## 5. Confidentiality and Trade Secret Hygiene

- Use NDAs with contractors and advisors.
- Restrict repository access to need-to-know.
- Keep secret parameters and proprietary weighting logic outside public docs.

## 6. Immediate Actions

- Freeze a versioned IP snapshot for current release.
- Prepare 2-3 focused claim themes (method, system, and implementation).
- Engage IP counsel and schedule claim drafting sprint.
